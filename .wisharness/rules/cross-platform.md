# 跨平台兼容

按产品契约、支持矩阵及 capabilities.settings.platforms 确定目标平台，不默认支持全部操作系统；列表为空记 not_evaluated，不以开发机代替全部支持范围。

涉及路径、进程、Shell、权限、编码、换行符、大小写、原生模块或平台 API，须显式检查各目标平台行为。使用标准跨平台 API 或明确平台分支；测试覆盖适用分支、错误语义及边界，不写死本机路径、不用 skip 回避。

用 `.wisharness/templates/platform-matrix.md` 逐平台记录实现影响、测试入口、运行环境、结果及证据。模拟测试证明逻辑分支，真实平台测试证明运行环境，不能互代。

CI/Runner、打包和签名由项目适配；缺 Runner 须说明阻塞与补验计划，不用本机结果替代。支持平台的必需门禁未运行或失败，不得标可发布；合并门禁沿用项目政策。

真实 OS、安装、协议注册、权限及原生能力须用最终交付形态验证，替换被测对象的夹具不证明真实性。
