# 产物字段

## diagnosis.csv（一行一个机会）

| 列 | 含义 |
|---|---|
| 机会编号 | O-001 起，按决定（测试 → 先补研究 → 观察 → 守住 → 转产品 → 暂不做 → 不适用）、业务优先级、竞争格局、题号排序 |
| 对象 | 「品牌」「SKU：<名>」「事实：<编号>」 |
| 题号、题面、主题、类型、业务优先级 | 来自题库；SKU 和事实行的题号是涉及的全部题 |
| 有效回答 | 合并后的分母；事实行是写错的回答数 |
| 本品提及率、领先竞品、领先竞品提及率 | 带分子分母；领先竞品只在同类品牌里找 |
| 官网进检索率、官网被引率 | 只用有检索字段的平台；SKU 行是该 SKU 页 |
| 推荐分布 | 被提及回答里各推荐状态的条数；对比题是首推胜负；SKU 行是 SKU 出现率 |
| 过门情况 | 门 0–3 哪道没过，或「通过」「已领先」「点名题」「不适用」 |
| 断点 | 第一断点编号和名称；「未定位」 |
| 主原因（假设） | 断点对应的原因假设，待三项核对 |
| 证据 | 数字、引用页、标注原句 |
| 证据强度 | 实测 / 推断（写明缺什么）/ 模型标注 |
| 次要发现 | 其他成立的断点、平台分歧、事实错误指向、不可观察的层 |
| 分平台读数 | 各平台本品提及率、官网被引率和条数；平台方向不同时结论分平台写，不合并 |
| 决定 | 测试 / 观察 / 先补研究 / 守住 / 转产品 / 暂不做 / 不适用 |
| 载体、缺口、信息怎么变好（候选）、最接近的现有页面（候选，需人确认） | 动作四要素；页面候选取自检索和引用里出现过的官网页面 |
| 主指标、对照题组、最早复测 | 度量契约；对照题组是同主题同类型、本期没派动作的题 |
| 负责方 | 内容团队 / 渠道与 PR / 官网技术 / 品牌方 |

## diagnosis.md

自动初稿：数据与口径（平台、强制联网、可达性、标注和页面抓取覆盖、阈值）→ 结论分布 → 每条「测试」「先补研究」的展开 → 其余决定的表。交内容团队前由分析师按 SKILL.md 第 5 步改写。
